A one-line office joke, written by a program for the
[Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

`main.py` writes a single one-line joke about office life to
`/output/entry.txt`.
